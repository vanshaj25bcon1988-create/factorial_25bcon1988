# Factorial Calculator 🐍

A simple Python program that calculates the **factorial of a number** using an iterative `for` loop.

## 📌 Project Description

This project demonstrates how to calculate the factorial of a given number in Python.

The program initializes a number and calculates its factorial by multiplying all integers from `1` up to that number. The current implementation calculates the factorial of `5`.

### What is a Factorial?

The factorial of a non-negative integer `n` is the product of all positive integers less than or equal to `n`.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## ✨ Features

* Simple and beginner-friendly Python implementation
* Uses an iterative `for` loop
* Calculates factorial efficiently for basic integer values
* Displays the calculated factorial in a readable format
